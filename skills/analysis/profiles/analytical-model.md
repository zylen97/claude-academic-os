# Profile: analytical-model（解析建模：博弈 / 合同 / 运营模型 + 数值研究）

> 一页纸检查清单，不是阻断器。项目特有的选择写在 `analysis_plan.md`，本文件只给方法层的必查项。

## 1 适用范围

博弈论模型（Stackelberg、Nash、讨价还价）、合同与机制设计（甄别、道德风险、期权式合同）、供应链与运营决策模型；可附带数值研究（参数化仿真、两阶段随机规划、MILP/MINLP 算例）。结论主要来自推导，数值部分只用于说明、扩展或检验解析结论的稳健性。不适用于以拟合数据为目的的计量或结构估计（用 `panel-regression` / `_generic`）。

## 2 输入（模型设定）

不需要数据包；输入是模型设定，写在计划第 3 节，展开在 `structure/3_analysis/derivation/`：
- 参与者、决策变量、时序（含签约 / 信息揭示 / 执行各时点）、信息结构（谁在何时知道什么）；
- 收益 / 成本函数、约束（IR、IC、有限责任、容量、可行域）；
- 假设清单：每条一句话写明经济含义与合理性来源（文献、制度事实、简化理由）；
- 符号表与参数定义域（所有正性、次序、上下界条件）；
- 数值研究另需：参数取值及来源（文献 / 案例 / 政策文件 / 标定，逐项注明）、情景生成方式与数量、求解器与版本、最优性间隙、随机种子。

## 3 结论目标（命题）

每个 RQ 落到可证明或可计算的目标：最优 / 均衡解的存在性与唯一性、最优合同结构（哪些约束紧、租金归谁）、比较静态的符号、阈值条件与区域划分、模型间排序（如完全信息 vs 非对称信息、有无自有能力）、价值量（信息价值、柔性价值、VSS/EVPI）。尚未推出的结论在计划中标"待证"，推不出时进入登记表为 null，不得改写成"数值上看起来成立"。

## 4 证据类型

`assumption`｜`equilibrium`（最优解 / 均衡解闭式或刻画）｜`lemma`｜`proposition`｜`comparative-static`｜`threshold`｜`verification`（符号 / 数值复核结果）｜`numeric`（数值研究结果）｜`sensitivity`｜`null`（登记过但推不出或被反例否定的待证结论）｜`table`｜`figure`

## 5 必做检验

1. **二阶条件 / 凹性**：目标函数对决策变量的 Hessian 或拟凹性；不满足时给出最优性的替代论证。
2. **内点解与角点解**：内点解成立的参数条件；越界时的角点解形式。
3. **可行域与参数约束**：所有闭式解在定义域内为正、满足容量 / 非负约束；列出使结论成立的参数条件。
4. **约束结构核验**（合同 / 机制类）：放松问题的解满足被省略的约束（如单调性、另一类型的 IC、IR）；紧约束模式与租金归属一致。
5. **比较静态**：每个符号结论写明成立条件；条件依赖时给出阈值，不得只报"一般成立"。
6. **符号复核**：用 SymPy / Mathematica 复核一阶条件、闭式解、关键不等式；脚本与输出放 `derivation/checks/`。
7. **数值复核**：在参数定义域内随机抽样检验命题不等式，报告抽样范围、次数与反例数；有反例时回到推导，不得删掉反例。
8. **数值研究**（若有）：参数来源表；求解器、最优性间隙、运行时间；情景数量的稳定性（样本内 / 样本外）；关键参数的敏感性；随机规划报告 VSS 或 EVPI（若与 RQ 相关）。
9. **拟合优度**：不适用（不得以"模型拟合良好"一类说法替代以上检验）。

## 6 报告顺序

问题描述 → 假设与符号（符号表）→ 基准模型（如完全信息 / 无自有能力）→ 主模型 → 最优解 / 均衡 → 命题与比较静态（每个命题后接管理直觉）→ 扩展模型 → 数值研究（参数设定与来源 → 结果 → 敏感性）。完整证明放附录，正文给证明思路或关键步骤。

## 7 解读边界

- 命题只在所列假设与参数定义域内成立；推广到连续类型、多期或多主体需另行证明。
- 数值算例与案例参数是示意，不是实证证据；不得写成"实践中会发生"。
- "最优"是相对模型目标函数而言；不得暗示对社会福利或真实企业最优，除非模型就是这样定义的。
- 比较静态的符号受阈值条件约束，引用时必须连同条件。
- 推不出的待证结论不得以数值观察替代证明而写成命题。

## 8 空洞表述信号

- "x* is increasing in θ" 之类只陈述符号、不说明对谁意味着什么的句子；
- "the IC constraint binds" 而不说明谁获得信息租金、运营方为此付出什么；
- "Proposition 2 shows that ∂K*/∂ρ > 0" 只复述命题，没有管理含义；
- "the numerical results confirm the analytical findings" 不说明确认了哪个结论、在什么参数范围内；
- 用模型内部记号（λ, μ, 情景索引）充当结论主语。
