# Profile: survey-sem（问卷调查 + 结构方程模型）

> 一页纸检查清单，不是阻断器。项目特有的选择写在 `analysis_plan.md`，本文件只给方法层的必查项。

## 1 适用范围

基于问卷量表的潜变量模型：CB-SEM（lavaan / AMOS / Mplus）与 PLS-SEM（SmartPLS / seminr），含中介、调节、多群组比较。CB-SEM 与 PLS-SEM 的选择及理由在计划第 3 节写明，下列阈值按所选方法取用。

**时序**：计划可以在数据到达之前批准（设计先于数据）。数据入库后在计划第 7 节追加一行"数据入库"（表格行 `| YYYY-MM-DD | 数据入库：回收 N 份、有效 n 份，文件 data/raw/… | 正式数据到达 | 无设计改动，Run 可开始 |`），不需要重新批准；只有改动构念、量表、模型或假设时才走变更确认。

## 2 输入（数据包）

- 总体、抽样框、抽样方式、发放渠道与时间、回收率与有效率、剔除规则（注意力题、作答时长、规律作答）；
- 量表来源、改编、翻译与回译、专家评审、预调研结果；
- 样本量依据（N:q 比、功效分析或 Monte Carlo）；
- 伦理审批或知情同意说明；
- 数据清洗：缺失处理、正态性、异常值；
- 原始问卷数据在 `data/raw/`（只读），脚本在 `data/scripts/`，输出在 `data/results/`。

## 3 结论目标（效应）

每个假设对应一条路径系数、间接效应（含置信区间）或调节效应；多群组比较对应群组间差异检验。预先写出每条假设的方向。

## 4 证据类型

`sample`｜`measure`｜`reliability`｜`validity`｜`cmb`｜`fit`｜`path`｜`indirect`｜`moderation`｜`invariance`｜`robustness`｜`null`｜`table`｜`figure`

## 5 必做检验

1. **非回应偏差**：早晚回复比较或与总体特征比较。
2. **信度**：因子载荷（≥ 0.70，0.60–0.70 需说明）、Cronbach's α、CR ≥ 0.70。
3. **收敛效度**：AVE ≥ 0.50。
4. **区分效度**：HTMT < 0.85（概念相近时 < 0.90）；Fornell–Larcker 作补充。
5. **共同方法偏差**：程序控制 + 统计检验；Harman 单因子只作最低限度，另做标记变量法或 ULMC / CLF。
6. **拟合**（CB-SEM）：χ²/df、CFI 与 TLI ≥ 0.90（理想 ≥ 0.95）、RMSEA ≤ 0.08（理想 ≤ 0.06）、SRMR ≤ 0.08；测量模型与结构模型分别报告。PLS-SEM：SRMR、R²、Q²、f²、内部 VIF < 3.3。
7. **间接效应**：bootstrap（≥ 5000 次）置信区间；不用 Sobel 作为唯一依据。
8. **调节**：交互项或多群组；多群组比较前做测量不变性（形态、度量、标量）。
9. **替代模型**：与竞争模型比较（若计划登记）；控制变量纳入与否的稳健性。

## 6 报告顺序

抽样与数据收集 → 测量（量表来源与题项表）→ 数据筛查与共同方法偏差 → 测量模型（信度、效度、拟合）→ 结构模型（拟合、按假设报告路径）→ 中介与调节 → 稳健性 / 替代模型。

## 7 解读边界

- 截面问卷只能支持关联与理论一致性，不能确立因果方向或时间先后。
- 自评数据的共同方法偏差即使检验通过也不能完全排除，表述为"不太可能主导结果"。
- 路径不显著 ≠ 构念之间无关系。
- 样本代表性限定结论适用的总体（行业、地区、职位）。
- R² 是解释比例，不是预测能力。

## 8 空洞表述信号

- "H1 is supported (β = 0.32, p < 0.001)" 后没有一句说明对研究对象意味着什么；
- "the measurement model fits the data well" 不给指标值；
- "X positively influences Y" 在截面设计中使用因果动词；
- 用构念缩写（如 DCAP → OPF）连成句子而无实义描述。
