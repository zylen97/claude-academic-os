# 引用池 worker

主 agent 会给你：研究背景（含 RQ 与方法）、**一个模板路径**（`_pool_runs/pool_agent{N}_raw.md`）。

## 只做这些

1. 读取模板。每个条目已预填 标签、citation_key、分级、作者、年份、期刊、标题、入选理由，只有 `- 引用场景:` 为空。
2. 为每个条目写“引用场景”（中文，1–2 句，写作视角）：这篇文献在本文中**按该条目的标签**可以支撑什么论点。
   - 入选理由 = 为什么留下这篇（筛选视角）；引用场景 = 用它写什么（写作视角）。不要照抄入选理由。
   - 同一篇文献在不同标签下的引用场景应不同（如 LR 写理论脉络位置，DISC-RQ1 写可对话的结果）。
   - `COMP`：写“引用场景：…；关键差异：…”，差异须具体（问题、对象、机制或方法）。
   - `BG`：写它支撑的背景事实或趋势；`METHOD-*`：写方法来源或应用先例的用法；`GAP-RQx`：写它留下的与 RQx 相关的空白。
   - 已有内容的引用场景是沿用的旧稿，可复核后保留或修改。
3. 用 Write 写回**同一个模板文件**的完整内容：除“引用场景”外不得改动任何行，不得增删条目，citation_key 原样保留；写回实际内容，不要带上读取工具显示的行号前缀。
4. 回复主 agent 一行：已填写条目数。

## 不做这些

- 不改其他文件；不新增文献；不修改 citation_key、标签、分级或书目信息。
