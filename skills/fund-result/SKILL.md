# /fund-result — 提交与结果登记

**规格**：`~/.claude/skills/shared/FUND-PROTOCOL.md`（下称"协议"）。本 skill 是 `submitted`、`awarded`、`rejected`、`未申报` 四个阶段的唯一写入方。

**输入** `$ARGUMENTS`：`submit | result | abandon`，可再跟项目文件夹名。不带文件夹名时，按当前目录判断；当前目录不是项目时，列出可操作的项目让用户选：

- submit：阶段为 `polishing`（或更早）的项目
- result：阶段为 `submitted` 的项目
- abandon：阶段为 `submitted` 之前的项目

不带模式时 AskUserQuestion 选模式。

## submit：提交登记

1. **确认提交了什么**：AskUserQuestion 询问实际提交的文件（默认列出 `deliverables/` 里的文件和项目根目录里像提交版的 PDF、docx），以及提交日期（默认今天）。
2. **冻结提交版**：把用户确认的文件**复制**到 `submitted/`（不移动原件）。文件名前加日期：`{YYYY-MM-DD}_{原文件名}`。`submitted/` 里已有同名文件时停止并询问，不覆盖。
   - 只能在系统里填、本地没有成品的（如在线填报）：请用户从系统导出或打印成 PDF 后放进来；导不出就把 `deliverables/系统填报稿.md` 复制进 `submitted/`，并在 FUND.md 的提交版字段注明"系统内容以填报稿为准"。
3. **改 FUND.md**：阶段 → `submitted`；提交日期 → 实际日期；提交版 → `submitted/`；经费、项目组成员如有最终值一并更新。
4. **刷新台账**：运行 `python3 "$FUNDINGS/_scripts/build_portfolio.py"`。
5. 提示：结果出来后运行 `/fund-result result`。档案里有结果公布时间的，告诉用户大致什么时候出结果。

## result：结果登记

1. AskUserQuestion：立项还是未中；结果日期；批准经费和项目编号（立项时）。
2. **评审意见**：询问有没有专家评审意见（NSFC 等会在系统里返回）。
   - 有 → 请用户粘贴原文或给出文件路径，存为 `reviews/评审意见_{年度}.md`：

     ```markdown
     # 评审意见（{年度} {基金}，结果：{立项/未中}）

     > 来源：{系统导出 / 用户粘贴}，登记日期 {YYYY-MM-DD}

     ## 专家 1
     {原文，不改写}

     ## 专家 2
     ...

     ## 汇总
     | 问题归类 | 涉及专家 | 要点 |
     |---|---|---|
     ```

     原文一字不改；汇总表由主 agent 归类（立项依据、研究内容、方案可行性、创新性、研究基础、表述与格式），归类后给用户确认。
   - 没有 → FUND.md 评审意见字段写"无（该基金不返回）"或"无（未获取）"。
3. **复盘**：根据评审意见和用户口述，写 FUND.md 的 `## 复盘`：中或没中的主要原因、下次要改的 3 条以内。复盘草稿先给用户确认再写入。
4. **改 FUND.md**：
   - 立项：阶段 → `awarded`；结果 → 立项；经费、结果日期、评审意见摘要
   - 未中：阶段 → `rejected`；结果 → 未中；结果日期、评审意见摘要
5. **立项后的后续**：
   - 提醒把项目写进 `_assets/{代码}/成果清单.md` 的"主持的科研项目"表（编号、起止、经费）。这一步改素材库，改之前征得用户同意。
   - 档案里有执行期要求（如成果须标注资助字样和编号）时，写进 FUND.md 的 `## 复盘` 末尾"执行期注意"。
6. **未中后的后续**：AskUserQuestion 是否计划重申。计划重申 → 告诉用户下一轮申报窗口（来自档案），并提示到时运行 `/fund-init 重申 {本项目文件夹名}`。
7. **刷新台账**：运行 `build_portfolio.py`，报告该申请人更新后的命中率。

## abandon：未申报登记

1. AskUserQuestion 确认原因（来不及、不符合条件、换了基金等），一句话即可。
2. 改 FUND.md：阶段 → `未申报`；结果 → `—`；`## 复盘` 写原因。项目文件夹和其中的资料保留不动。
3. 刷新台账。

## 注意事项

- 只改本项目的 FUND.md、`submitted/`、`reviews/`；改素材库前必须征得同意。
- `submitted/` 里的文件冻结后不再修改；后续修改一律在 `sections/` 或 `deliverables/` 里做。
- 评审意见原文不改写、不润色。
