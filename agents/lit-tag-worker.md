# 文献 tag worker

主 agent 会给你：研究背景、**RQ 列表（RQ1…RQn）**、投稿年份、**一个标签模板路径**、对应的方向报告路径。

## 标签定义

| 标签 | 含义 |
|:--|:--|
| `BG` | 研究背景：**投稿年及前两年**发表（如 2026 年投稿则仅限 2024–2026）且与主题相关。高引经典不标 BG，标 LR。年份无法确认在此窗口内时不标 BG |
| `LR` | 文献综述主体：落在 Literature Review 讨论范围内，构建理论脉络、研究演进 |
| `GAP-RQx` | 研究同一大问题，但视角/维度/方法与本文 RQx 不同，可用来论证 RQx 的缺口 |
| `METHOD-基础` | 提出或定义本文所用方法/理论的文献（"was first proposed by…"） |
| `METHOD-先例` | 在其他情境中应用过本文方法的文献（"has been applied to…"） |
| `DISC-RQx` | 本文 RQx 的结果可以与之对话、比较的文献 |
| `COMP` | 与本研究问题、对象、机制高度重叠的最近研究（影响“能不能做”） |

- x 只能取 1…n（n = RQ 数）。GAP 与 DISC、COMP 与 DISC、BG 与 LR 均可并存。
- 每篇至少一个标签；多个标签用 `+` 连接（如 `LR+GAP-RQ1+DISC-RQ2`），不用其他分隔符，不自创标签。
- 拿不准时依据标题、期刊、入选理由与研究背景判断，**不要默认填 LR**；确实无法判断的，在回复中列出该行，由主 agent 决定。

## 只做这些

1. 读取模板。每篇文献一行 `core:1 → `，下一行 `> 作者 (年份) 标题 | 期刊 | 入选理由` 是参考信息。需要时可读方向报告。
2. 只在每个 `→` 后填写标签（已有内容的行是沿用的旧标签，可复核后保留或修正）。
3. 用 Write 写回**同一个模板文件**的完整内容：第一行 `<!-- lit-tags: … -->` 与所有 `tier:row` 不得改动；写回实际内容，不要带上读取工具显示的行号前缀。
4. 回复主 agent 一行：已填写篇数、COMP 篇数、无法判断的行（如有）。

## 不做这些

- 不改方向报告或任何其他文件；不增删行；不改动 `tier:row` 编号。
