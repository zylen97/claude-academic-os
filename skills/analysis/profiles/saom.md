# Profile: saom（随机行动者导向模型，RSiena）

> 一页纸检查清单，不是阻断器。项目特有的选择写在 `analysis_plan.md`，本文件只给方法层的必查项。不要照搬基准论文的效应列表。

## 1 适用范围

纵向网络演化与网络—行为共演化的随机行动者导向模型（SAOM，通常用 RSiena 实现）。不适用于截面网络（用 ERGM 等，走 `_generic`）。

## 2 输入（数据包）

估计前锁定：
- 行动者定义、行动者集规则、进出时点与构成变化处理；
- 有向 / 无向、关系定义、事件到波次的聚合与投影规则、结构性 0/1；
- 波次与转换期、观测窗口、行为变量时点与滞后；
- 因变量网络、行为变量、行动者 / 二元协变量的构造、变换、中心化、取值范围、缺失处理；
- 关系构造、伙伴协变量与行为度量之间的机械重叠；
- 可行性：各波次行动者数与构成、密度、度分布、孤立点、互惠（如适用）、变化数；每个转换期的 Jaccard 系数（经验上 ≥ 0.3，< 0.2 需特别论证）；行为变量的分布与个体内变化、天花板 / 地板集中；协变量变异是否足以识别每个计划效应。
数据在 `data/raw/`（只读）→ `data/processed/`，脚本在 `data/scripts/`，模型对象在 `data/models/`，输出在 `data/results/`。

## 3 结论目标（效应）

每个 RQ 对应目标函数中的具体效应或效应对比（选择 / 影响 / 结构效应），以及需要的时间异质性对比。选择、行为、关联、预测、因果五类目标严格区分。

## 4 证据类型

`data`｜`method`（软件版本、效应注册、估计设置）｜`estimate`｜`convergence`｜`time-heterogeneity`｜`gof`｜`robustness`｜`sensitivity`｜`null`｜`limit`｜`table`｜`figure`

## 5 必做检验

1. **输入完整性**：行动者与波次对齐、取值合法、缺失 / 结构编码、对称性（无向网络）。
2. **收敛**：总体最大收敛比 < 0.25；所有参数收敛 t-ratio 绝对值 < 0.1；标准误无异常。
3. **模型设定**：效应在当前 RSiena 版本可用；速率与目标函数区分；参数协方差无高度相关（避免弱识别组合）。
4. **时间异质性**：多转换期时用 score / Wald 检验（`sienaTimeTest`）；不得因"一期显著另一期不显著"推断时间差异。
5. **拟合优度**：基于模拟的辅助统计（入度、出度、测地距离、三元组普查；行为分布），报告每项的 Monte Carlo p 值与残余失拟；GOF 必须基于主模型对象本身。
6. **稳健性 / 敏感性**：只跑计划登记的替代设定，每项注明对应的主模型。
7. **稳定性**（若计划登记）：不同种子复跑比较估计与收敛；不得称为独立重复。
记录 R 与 RSiena 版本、算法设置、种子、warm start 来源。

## 6 报告顺序

数据边界（行动者、波次、关系定义）→ 描述统计与 Jaccard → 变量度量 → 模型设定（速率、效应及其公式）→ 估计设置 → 收敛 → 按 RQ 报告结果 → 时间异质性 → GOF → 稳健性。

## 7 解读边界

- 目标函数参数是模型化微观过程中的条件倾向，不是概率、边际效应、实现的关系数量或因果效应。
- 系数正负只描述给定其他效应下的条件倾向，不证明所命名的机制。
- 行为相似 / 影响效应本身不证明实际趋同、学习或知识转移。
- 同类效应与跨类偏好不可互换，除非编码与对比确立这种关系。
- 时间变化的说法需要正式对比。
- GOF 只说明对所评估辅助统计的充分性，不是外部效度。
- 稳健性只说明在登记的替代设定下稳定，不是独立重复；统计上不支持 ≠ 不存在。

## 8 空洞表述信号

- "the evaluation function effect of X is positive" 而不翻译成行动者在什么情况下更倾向于做什么；
- "candidate states"、"objective function"、"micro-step" 等模型内部词汇充当结论主语；
- "the parameter is significant" 不给方向与实质含义；
- "the model converged well" 不给收敛指标。
